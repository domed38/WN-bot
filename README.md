How to install on windows:
    Bluestacks - https://www.bluestacks.com/
    Python - https://www.microsoft.com/store/productId/9PNRBTZXMB4Z?ocid=libraryshare OR https://www.python.org/downloads/

Once all of those are installed, open CMD and run:
    pip install pyautogui pygetwindow keyboard
    python -m pip install pyautogui pygetwindow keyboard
    py -m pip install pyautogui pygetwindow keyboard



Run Bluestacks as many bluestacks instances as you'd like (PIE 64-bit is recommended) and turn off ads (Settings -> Preferences -> Allow Bluestacks to show ads during gameplay)
Now run all instances of bluestacks, sign into your Google Play account, and install WhatNot. 
(it is recommended to create a WN account before you install it on bluestacks on your phone (you should use my link to get extra rewards www.whatnot.com/invite/domed) to prevent getting banned)
(you will have to put in a shipping address and a payment method, but it will not be charged for anything)
Run all instances in windowed mode and select a catagory you want to go for (pokemon gets pokemon packs, everyday electronics gets amazon giftcards, etc.)
Try to find a page that is already running a giveaway to stay on, and make sure allo instances are on different streams.
Once all WN pages are ready, lay out all screens and run the program, in cmd run "pyhton C:/PathToProgram/WN-bot.py" and let it run.
Open the CMD window and press "ctrl + c" to stop the program.
